# YECO Boshqaruv

YECO CLIMATE xodimlari uchun dastur: subsidiya buyurtmalari, kalkulyator va KP, montaj, ombor, servis.

- Veb-dastur: https://yecoclimateuz-cloud.github.io/yeco-app/
- Android APK: https://github.com/yecoclimateuz-cloud/yeco-app/releases/download/apk/YECO.apk

Server (Supabase) ulash: `config.js` faylidagi ikki qatorni to'ldiring va maxfiy sozlash faylini (SQL) Supabase SQL Editor'da bir marta ishga tushiring. Parollar bu papkada saqlanmaydi.
